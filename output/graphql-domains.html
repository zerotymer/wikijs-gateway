wikijs-agent-gateway
│ Authorization: Bearer WIKIJS_API_TOKEN
▼ POST WIKIJS_GRAPHQL_URL
Wiki.js /graphql → PostgreSQL → Git storage

Wiki.js API Token 최소 권한

권한용도
read:pagesGetPageByPath 쿼리, Ping 쿼리
read:sourcecontent 필드 접근
write:pagesUpdatePage, CreatePage 뮤테이션

manage:system, delete:pages, manage:users는 부여하지 않는다.

Queries

Query GetPageByPath pages.singleByPath

사용 위치: GET /pages/by-path POST /pages/dry-run POST /pages/patch-section POST /pages/upsert (내부)

GraphQL 쿼리
query GetPageByPath($path: String!, $locale: String!) {
  pages {
    singleByPath(path: $path, locale: $locale) {
      id
      path
      title
      description
      content
      editor
      locale
      isPublished
      isPrivate
      updatedAt
      scriptCss
      scriptJs
      tags { tag }
    }
  }
}
변수
변수타입설명
$pathString!Wiki.js 경로 (leading slash 제거 후 전달)
$localeString!locale 코드 (예: ko)
특이사항

페이지 미존재 시 Wiki.js가 null 대신 GraphQL error code 6003(PageNotFound)을 반환한다.
Gateway는 이 경우를 404로 변환하고, 그 외 에러는 502로 변환한다.

Query Ping pages.list (limit:1)

사용 위치: GET /health (wikijsReachable 판단)

GraphQL 쿼리
{ pages { list(limit: 1) { id } } }
특이사항

응답에 errors 필드가 없으면 wikijsReachable: true 반환.
네트워크 예외나 HTTP 에러 발생 시에도 false만 반환하고 예외를 전파하지 않는다.

Mutations

Mutation UpdatePage pages.update

사용 위치: POST /pages/patch-section (write 모드) POST /pages/upsert (기존 페이지 갱신)

GraphQL 뮤테이션
mutation UpdatePage(
  $id:          Int!
  $content:     String!
  $title:       String
  $description: String
  $editor:      String
  $locale:      String
  $isPublished: Boolean
  $isPrivate:   Boolean
  $tags:        [String]
  $scriptCss:   String
  $scriptJs:    String
) {
  pages {
    update(
      id: $id
      content: $content
      title: $title
      description: $description
      editor: $editor
      locale: $locale
      isPublished: $isPublished
      isPrivate: $isPrivate
      tags: $tags
      scriptCss: $scriptCss
      scriptJs: $scriptJs
    ) {
      responseResult { succeeded errorCode message }
      page { id path title updatedAt }
    }
  }
}
에러 처리

responseResult.succeeded == false인 경우 Gateway는 WikiJsError로 변환 후 502 반환.
patch-section에서는 write 모드 + allowlist 통과 후에만 호출된다.

Mutation CreatePage pages.create

사용 위치: POST /pages/upsert (신규 페이지 생성)

GraphQL 뮤테이션
mutation CreatePage(
  $content:     String!
  $description: String!
  $editor:      String!
  $isPublished: Boolean!
  $isPrivate:   Boolean!
  $locale:      String!
  $path:        String!
  $tags:        [String]!
  $title:       String!
) {
  pages {
    create(
      content: $content
      description: $description
      editor: $editor
      isPublished: $isPublished
      isPrivate: $isPrivate
      locale: $locale
      path: $path
      tags: $tags
      title: $title
    ) {
      responseResult { succeeded errorCode message }
      page { id path title updatedAt }
    }
  }
}
특이사항

upsert_page는 먼저 GetPageByPath로 존재 여부를 확인 후,
존재하면 UpdatePage, 없으면 CreatePage를 호출한다.
