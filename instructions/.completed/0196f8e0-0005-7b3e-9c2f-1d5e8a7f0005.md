# Step 5: Docker 독립 배포 + 운영 검증

## 환경 전제

- Wiki.js는 이미 `http://192.168.28.10:23000`에서 운영 중 (외부: `https://md.zerotymer.net`)
- Gateway는 **독립 컨테이너**로 실행 — 별도 base `docker-compose.yml` 불필요
- `docker-compose.gateway.yml` 단독으로 `docker compose -f docker-compose.gateway.yml up`
- `.env`에 `WIKIJS_GRAPHQL_URL=http://192.168.28.10:23000/graphql` 설정

## 목표

실제 Wiki.js에 연결된 gateway를 기동하고 read_only → dry_run → write 순서로 검증한다.
이 단계 완료 후 운영 배포 준비 상태.

## 완료 조건

- [ ] `docker compose -f docker-compose.gateway.yml up -d --build` 성공
- [ ] `GET /health` → `wikijsReachable: true`
- [ ] read_only → dry_run → write 모드 순차 전환 및 각 단계 검증 통과
- [ ] audit 파일 생성 확인
- [ ] Security Checklist 항목 전체 확인

## 구현 체크리스트

### 사전 준비

- [ ] `.env` 완성: WIKIJS_GRAPHQL_URL, WIKIJS_API_TOKEN, GATEWAY_TOKEN, GATEWAY_MODE 등
- [ ] `requirements.txt` 버전 최종 고정 (완료: 정확한 버전으로 핀)
- [ ] `docker-compose.gateway.yml` `restart: unless-stopped` 확인 (이미 설정됨)

### Docker 빌드 검증

```bash
docker build -t wikijs-agent-gateway:local .
```

- [ ] 빌드 성공
- [ ] 이미지 크기 확인 (python:3.12-slim 기준 ~200MB 이하 목표)
- [ ] `USER nobody`로 실행 확인: `docker run --rm wikijs-agent-gateway:local whoami`

### Phase 1: read_only 모드

```bash
GATEWAY_MODE=read_only docker compose -f docker-compose.gateway.yml up -d --build
```

- [ ] `GET /health` → `{"ok": true, "mode": "read_only", "wikijsReachable": true}`
- [ ] `GET /pages/by-path?path=<기존경로>` → page 반환
- [ ] `POST /pages/dry-run` → 403 차단 확인

### Phase 2: dry_run 모드

```bash
GATEWAY_MODE=dry_run docker compose -f docker-compose.gateway.yml up -d
```

- [ ] `POST /pages/dry-run` → diff 반환 (실제 Wiki.js mutation 없음)
- [ ] audit 파일 생성 확인 (`gateway-audit` volume)
- [ ] PAGE_CHANGED 시나리오 검증 (baseHash 임의 변조 → 409 유사 응답)

### Phase 3: write 모드 (테스트 경로 한정)

```bash
GATEWAY_MODE=write ALLOW_PATH_PREFIXES=/agent,/draft \
  docker compose -f docker-compose.gateway.yml up -d
```

- [ ] `POST /pages/patch-section` — `/agent/test` 경로 page 수정 성공
- [ ] `POST /pages/upsert` — `/agent/test` 신규 page 생성 성공
- [ ] `/ops/runbook/` 경로 → 403 차단 (allowlist 미포함)
- [ ] Wiki.js UI (`https://md.zerotymer.net`)에서 수정 내역 확인

### Security Checklist 최종 확인

- [ ] Gateway는 `127.0.0.1:8088`에만 bind
- [ ] `GATEWAY_TOKEN`이 `.env`에만 있고 코드에 없음
- [ ] `WIKIJS_API_TOKEN`이 응답에 노출되지 않음
- [ ] `ALLOW_PATH_PREFIXES` 설정 확인
- [ ] `RENDER_AFTER_WRITE=false` (기본값)
- [ ] audit 파일에 token 값 노출 없음
- [ ] `.env` 미커밋: `git status` + `.gitignore` 확인

### 운영 준비

- [ ] README.md 빠른 시작 섹션 업데이트 (독립 배포 방식 반영)

## 배포 명령

```bash
# 기동
docker compose -f docker-compose.gateway.yml up -d --build

# 상태 확인
docker compose -f docker-compose.gateway.yml ps
docker compose -f docker-compose.gateway.yml logs -f wikijs-agent-gateway
```

## Rollback

```bash
docker compose -f docker-compose.gateway.yml stop wikijs-agent-gateway
```

Wiki.js, PostgreSQL, Git storage는 영향 없음.
