- [x] `_resolve_uuid_path` / `resolve_uuid_path`: 목록에 없으면 단건 조회 없이 404 (type 유무 무관, `/raw` 포함)

- [x] 테스트: Python (`test_routes_by_uuid`, `test_wikijs_client`, mock 기본값 갱신), Rust (`tests/api.rs`)
