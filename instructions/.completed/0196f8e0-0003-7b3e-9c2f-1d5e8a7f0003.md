# Step 3: Markdown Patch 로직 + Dry-run 엔드포인트

## 목표

`markdown_patch.py`와 `locking.py`를 완성하고 `POST /pages/dry-run`을 구현한다.
실제 Wiki.js 쓰기 없이 patch diff를 확인할 수 있어야 한다.

## 완료 조건

- [x] `tests/test_markdown_patch.py` 전체 통과
- [x] `tests/test_locking.py` 전체 통과
- [x] `POST /pages/dry-run` → `{"ok": true, "mode": "dry_run", "changed": true/false, "diff": "...", "newHash": "..."}`
- [x] baseHash 불일치 → `{"ok": false, "error": "PAGE_CHANGED", "currentHash": "..."}`
- [x] `GATEWAY_MODE=read_only`에서 `/pages/dry-run` 호출 → 403

---

## 구현 체크리스트

### `app/locking.py` (완성)

- [x] `compute_hash(page_id, updated_at, content) -> str`
  - `sha256(f"{page_id}\n{updated_at}\n{content}").hexdigest()`
  - 반환 형식: `"sha256:{hex}"`
- [x] `verify_hash(expected, page_id, updated_at, content) -> bool`
- [x] `PAGE_CHANGED` 에러 응답 생성 헬퍼

### `app/markdown_patch.py`

#### `append_under_heading(content, heading, text, create_heading=False) -> str`

- [x] heading text 정확 일치 검색 (`## Heading` 형태)
- [x] 일치하는 heading 다음 빈 줄 이후에 `text` 삽입
- [x] `create_heading=False`이고 heading 없으면 `HeadingNotFoundError` 예외
- [x] `create_heading=True`이면 파일 끝에 heading + text 추가
- [x] 추가 content는 newline으로 끝나도록 보장

#### `replace_between_markers(content, name, new_text) -> str`

- [x] `<!-- agent:start {name} -->` … `<!-- agent:end {name} -->` 범위 교체
- [x] marker 없으면 `MarkerNotFoundError` 예외
- [x] 교체 후 marker 태그는 유지

#### `replace_section(content, heading, new_section_content) -> str`

- [x] heading부터 다음 동일 레벨 heading 직전까지 교체
- [x] heading이 없으면 `HeadingNotFoundError` 예외
- [x] heading 레벨 파싱 (`#` 개수)

#### `compute_diff(before, after) -> str`

- [x] `difflib.unified_diff` 기반 unified diff 문자열 반환

### `app/models.py` 추가

- [x] `PatchOperation` (type, heading/name/content 등 operation별 필드)
- [x] `DryRunRequest` (path, locale, baseHash, operation)
- [x] `DryRunResponse` (ok, mode, changed, diff, newHash)

### `app/main.py` 수정

- [x] `POST /pages/dry-run` 엔드포인트
  - `GATEWAY_MODE == read_only` → 403 차단
  - page 조회 → hash 검증 → patch 계산 → diff 생성
  - 실제 Wiki.js mutation 없음
  - `changed=False`이면 diff는 빈 문자열
- [x] 모드 게이트 공통 함수 `require_mode(min_mode)` 추출
